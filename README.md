# Ryuki Sogabe — Portfolio

曽我部龍輝のエンジニアポートフォリオです。プロフィール、技術経験、個人開発、設計で大切にしていること、一般化した業務経験を掲載しています。

特定の企業・施設への志望動機ではなく、本人の経験・考え方・開発実績を伝える構成です。PokerForgeは個人開発のひとつとして紹介しています。

HTML / CSSのみで構成した、GitHub Pages向けの静的サイトです。ビルドや外部ライブラリのインストールは不要です。

グリーンを基調としたシンプルなデザインです。実画面は演習画面を大きく、開始画面を補助として配置し、原寸画像へのリンクを添えています。外部フォントやアニメーション用ライブラリには依存していません。

## ファイル

- `index.html`: 掲載内容とページ構成。
- `styles.css`: デザインとレスポンシブ表示。
- `.nojekyll`: Jekyllの処理を使用せず、静的ファイルを配信するための設定。
- `assets/pokerforge-home.jpg`, `assets/pokerforge-question.jpg`: ローカル開発版の画面。テスト用教材で撮影した開始画面と回答前の演習画面です。

## ローカルでの確認

`index.html` をブラウザで開いてください。CSSも同じフォルダに置きます。

## 掲載方針

業務経験は、顧客名や非公開の案件名・仕様・コードを含めず、担当範囲を一般化して記載しています。技術の経験年数、習熟度、数値成果は推定していません。個人開発のソースコードや第三者の解析データは含めていません。

PokerForgeは、本人提供のローカルソースで、教材生成CLIと学習PWAの構成、使用技術、採点・表示の分離、スキーマからの型・検証器生成を確認して紹介しています。ソルバー本体は既存のライブラリを利用しています。LLMとの連携機能は解説用プロンプトのコピーで、LLMが採点したり自動で解説を生成したりする機能とは区別しています。

公開URLではログイン画面を確認していますが、ローカル開発版はログインを使用しない別の構成です。掲載する機能がそのまま公開版で利用できると誤解されないよう、ページ内で区別しています。ローカルソースのコードや教材データは、このリポジトリに含めていません。

画面確認では、提供ソースのPWAを作業用ディレクトリにコピーしてビルドし、テスト用教材を使って出題・回答・採点・次問・用語集を確認しました。元のソースフォルダは変更していません。オフライン利用への対応はService Worker設定と実装に基づく記載で、今回の確認では通信遮断下の動作検証は行っていません。

## GitHub Pages

公開URL: <https://sogabe-ryuki.github.io/>

公開するファイルは `main` で管理します。リポジトリの **Settings → Pages → Build and deployment** の設定は次のとおりです。

- Source: **Deploy from a branch**
- Branch: **main**
- Folder: **/ (root)**

更新時は変更を `main` にpushし、GitHub ActionsのPagesデプロイ結果と公開URLの表示を確認します。このリポジトリには公開用ファイルのみを置き、既存の非公開リポジトリの公開範囲は変更しません。

参考: [GitHub Pagesの公開元設定](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)。
